# Track 1 methods-template coverage

The official methods spreadsheet contains voluntary questions; the separate Track 1 instructions require a brief methods report. The report remains concise, and this map records coverage.

| Template topic | Where addressed / status |
| --- | --- |
| Team name | Actual submitting username/team remains an operator input; no provisional identity in the report |
| Model number | To be assigned for the actual submission; no portal submission has occurred |
| Approach in detail | METHODS: Approach and data; frozen native configurations |
| Automated output or downstream review | METHODS distinguishes automated annotation, source-based review and supplementary AVI without reselection |
| Downstream review details | METHODS lists allele, disease, frequency, transcript, literature, read and phase review; EVIDENCE_REVIEW describes the ledger |
| Public or proprietary data | METHODS distinguishes controlled-access case data from public supporting resources |
| Public data used | METHODS names software, HPO/HGNC/ClinVar versions and literature; native database release appears in configurations |
| Proprietary data used | No additional proprietary dataset; case inputs remain subject to controlled-access terms |
| Pairs or single variants | Compound-heterozygous pairs; four submitted two-allele rows |
| Incidental findings | None submitted; all rows are primary alternatives |
| Runtime and cost | METHODS: recorded stage wall times; total effort and monetary cost not recorded |
| Abstract, maximum 500 words | English METHODS is checked to be at most 500 whitespace-delimited words, including title and references |
| AI disclosure (additional submission-page instruction) | OpenAI Codex; user-reported plan label and unverified data-handling settings explicitly stated |
| Added AVI method | METHODS and AVI.md describe scope, SDK, date, quantile cutoff, incomplete indels, fixed-cache replay and evidence dependence |

Source: the official Track 1 methods spreadsheet, frozen locally 28 August 2026, and the submission instructions checked 4 October 2026. This table is a coverage aid, not organizer approval.
